# Publishing and licensing controls

This repository is **public by the owner's choice** as of November 7, 2026.

## Required review for each new file
- Does it contain credentials, signing keys, private addresses, account identifiers, personal information, or financial records?
- Is it original content, licensed for redistribution, or a brief properly attributed research excerpt?
- Is the content intended to be public, and has it been inspected before upload?
- Are commercial claims distinguished from estimates and assumptions?

## Licensing
No open-source license has yet been selected for game source or original research. Public access **does not** grant a general right to reuse copyrighted content. Before shipping the game, choose licenses for code and each asset separately.

## Artifacts
The v0.4 printable PDFs and historical ZIP backups were not imported in this text-only migration. Do not imply otherwise. A future reproducible artifact build is preferable to repeatedly committing generated ZIP files.
