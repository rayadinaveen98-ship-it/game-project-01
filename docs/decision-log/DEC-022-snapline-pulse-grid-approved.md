# DEC-022 — Snapline Sprint P2 visual direction selection

**Date:** November 7, 2026
**Owner decision:** “For Snapline Sprint P2, I choose A. Review this direction and continue with the next visual refinement stage.”
**Status:** APPROVED for DIRECTION A. P2.1 screen refinement remains IN REVIEW.

## Locked by this decision
- Option A: **Pulse Grid** is the visual direction for first Snapline prototype.
- Core aesthetic: deep midnight navy, precise glowing mint line, coral hazards, clean geometry, restrained technical motion and a high-contrast, uncluttered arcade experience.
- No alternative visual directions (Ink Trail / Micro Runner) should be silently introduced into production screens.
- Existing P1 gameplay and collision handling remain authoritative.

## Not approved by this decision
- Exact final spacing, typography, decorative details and all future screens
- Character art, particle systems, sound design, effects library
- Gameplay B/C, release scope or the product's eventual visual identity beyond the prototype
- Native APK, commercial launch or branding/trademark clearance

## Next gate
P2.1 produces real, interactive Home, Gameplay, Result and Help screens in Pulse Grid. The owner reviews the browser screenshots **and** the playable HTML before final layout tokens are frozen. Any requested changes go into a change log and comparison screenshots.
