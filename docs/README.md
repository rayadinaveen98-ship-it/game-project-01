# Documentation governance

## Source of truth
Each major decision gets an ID, owner, date, rationale, status, and verification/approval evidence.

States: `OPEN`, `PROPOSED`, `APPROVED`, `SUPERSEDED`. Research materials and prototype existence do not imply approval.

## Evidence labels
- Designed: written specification or mockup exists.
- Implemented: source code exists.
- Built: reproducible build output exists.
- Tested: recorded test results exist.
- Approved: product owner explicitly accepted scope and quality.
- Released: shipping artifact and distribution evidence exist.

## Planned folders
- `01-pre-production/`: charter, production gates, project state.
- `02-market-research/`: comparators and dated source notes.
- `03-game-concepts/`: concepts and experiments (unpublished).
- `04-game-design/`: approved GDD and level systems.
- `05-art-direction/`: art bible, references, asset provenance.
- `06-technical-design/`: engine decisions and build pipeline.
- `07-testing/`: test plans, results, and regression evidence.
- `08-production-roadmap/`: milestones and scoped backlog.
- `decision-log/`: immutable historical decisions and revisions.

Until the repository visibility is private or disclosure is approved, unpublished research remains outside this public repository.
